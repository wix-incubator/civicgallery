# Civic Gallery

A cultural venue registration site showing event signup, visitor details, structured submissions, and confirmation routing powered by Wix Headless.

This website is powered by Wix Headless and built using [wix-headless.dev](https://www.wix-headless.dev).

## Live Site

- [https://civic-gall-5d87642b-gonenj.wix-site-host.com](https://civic-gall-5d87642b-gonenj.wix-site-host.com)

## Source

- [https://github.com/wix-incubator/civicgallery](https://github.com/wix-incubator/civicgallery)

## What It Showcases

- Forms experience built as a custom headless website
- Wix-managed backend capabilities surfaced through a custom Astro front end
- Public `llms.txt` and `robots.txt` configured through the Wix SEO txt APIs
- Deployment with `wix release`

## Local Development

```bash
yarn install
yarn dev
```

## Build

```bash
yarn build
```
